## Excel Clipboard Masker — защита числовых данных из Excel

**Аннотация:** Проект реализует фоновую утилиту для маскирования числовых значений при копировании диапазонов из Excel. Решение автоматически перехватывает табличный текст в буфере обмена, распознает числа и подменяет их на безопасные значения по заданным диапазонам. Это снижает риск утечек при пересылке или вставке данных, сохраняя рабочий процесс пользователей без изменений.

Проект ориентирован на офисные сценарии, где сотрудники регулярно копируют табличные данные, а чувствительные суммы должны быть скрыты без ручной обработки.

## Ключевые возможности

- Маскирование чисел по диапазонам (до 10k / до 100k / >100k)
- Обработка табличного текста из буфера обмена (TSV/строки с табами)
- Anti‑loop на основе хэша, чтобы избежать повторной переработки
- Запуск в режиме демона с логированием и корректной остановкой
- Минимальный набор unit‑тестов для критичных функций

## Как это работает

1) Пользователь копирует диапазон в Excel — в буфере появляется TSV‑текст.
2) Фоновый процесс читает буфер, находит числа и маскирует их по правилам.
3) При вставке пользователь получает уже безопасные значения.

Важно: используется **polling (опрос буфера)**, без системных хуков.

## Что внутри (структура)

- `src/cipher_engine.py`: алгоритм маскирования чисел по диапазонам (до 10k / до 100k / >100k)
- `src/clipboard_handler.py`: polling буфера, эвристика “похоже на таблицу”, маскирование и **anti-loop по MD5**
- `src/daemon.py`: запуск “как демон” (лог + корректная остановка по Ctrl+C)
- `src/main.py`: CLI‑входная точка
- `tests/`: минимальные unit‑тесты

## Установка

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

### Интерактивный режим (мониторинг буфера)

```bash
python src/main.py
```

Скопируйте диапазон в Excel (Ctrl+C) → вставьте куда‑нибудь (Ctrl+V) и проверьте, что числа подменились.

### Режим “демона” (лог + остановка Ctrl+C)

```bash
python src/main.py --daemon
```

Логи пишутся в `clipboard_daemon.log` (и в stdout).

## Тесты

Проект содержит тесты на `unittest`:

```bash
python -m unittest discover -s tests -v
```

Также в `src/main.py` есть флаг:

```bash
python src/main.py --test
```
